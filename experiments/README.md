# Experimental Result Snapshots

This folder stores lightweight, version-controlled snapshots of experiment results.
The raw `output/` directory is intentionally ignored because it contains generated
solution files and large run artifacts.

## Contents

- `output_csv/` preserves all CSV files copied from the ignored `output/`
  directory, keeping the same relative experiment structure.
- `irace/` stores the lightweight iRace tuning snapshot: the `.Rdata` object,
  tuning scenarios, and parameter search space.

These CSV files are the audit trail for the experiment batches used by the thesis.
They are small enough to keep in Git and can be used to regenerate summaries,
tables, and figures without committing the full raw output directory.

The command checklist and experiment protocol are documented in
`../docs/experiments.md`.

## Regeneration

The full raw outputs can be regenerated by running the experiment scripts with the
same instance lists, seeds, and parameter configuration. Generated `.txt` solution
files, logs, and intermediate run folders should remain outside Git unless a
specific file is needed for debugging or reproduction.
